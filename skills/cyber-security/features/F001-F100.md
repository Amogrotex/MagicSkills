# Cyber pack — 100 features (F001–F100)

Use with **Cyber Security**, **Attack Methods**, **Reverse Engineering**, **Stress Tests**, **Scanning**, **Issues Founder**.  
Each feature ID is a switch: include when relevant. Mark `done / skip / n/a / blocked`.

**Rules for all features:** authorized targets only · prefer owner systems · no weaponized exploit/malware code in outputs · attack content = classes, methods taxonomy, test *plans*, controls, detections.

---

## How to apply

| Effort | Features |
|--------|----------|
| **Fast** | Pick 5–10 highest signal IDs |
| **Balanced** | 15–30 by profile |
| **Max** | 40+ or full applicable set |

Profile packs (suggested ID sets) are at the bottom.
